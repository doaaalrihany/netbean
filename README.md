ملاحظة :
خوارزمية Quick( مش موجود ناتجها بسبب خطا في الكود معرفتش نعالجه) هدا الخطا سببه فيضان الداكرة لان الخوارزمية تاخد في العنصر الاول او الاخير ك pivot هدا مسبب عطل ومعرفتش نعالجه
------------------------

التحليل و المقارنة :
خوارزميات الاداء O(N^2) :
selsction sort
insertion sort
Bubble sort
تاخد وقت اطول ومعقدة لما نطبقها على حجم بيانات لان تعتمد على for وتتقاطع مع بعض بشكل متكرر 

خوارزميات الاداء O(n log n ) :
 merge sort
 Quick sort
 اسرع ومتاخدش وقت طويل لانها تقسم المصفوفة الى اجزاء اصغر وتتعامل معاها بكفاءة 

ايضا ف حالة البيانات المرتبة و المرتبة جزئيا تعتبر insertion sort تتعتبر اسرع وحدة فيهم لانها تكتشف ف ان العناصر ف مكانها الصحيح ومتاخدش ف وقت عند ترتيبهم 
عندنا  merge sort و Quick sort بشكل عام اسرع زوز في اغلب الحالات 
وفي المرتبة بشكل جزئي insertion sort اكتر كفاءة منهم
